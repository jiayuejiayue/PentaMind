# PentaMind Extension 插件

> 🦊 自动化渗透测试辅助浏览器扩展

本插件作为一个独立的浏览器扩展运行，负责在用户正常浏览网页时，在后台静默收集页面 DOM 结构（功能点、交互元素）和拦截底层 API 请求，推断可能存在的安全风险。

## 核心特性

- **DOM 扫描**：自动解析页面表单、按钮、输入框，识别登录、上传等敏感操作
- **API 流量拦截**：捕获页面发出的 XHR/Fetch 请求并进特征提取
- **智能关联**：基于时序和参数名称，将前后端 API 接口与前端 DOM 元素关联
- **独立运行**：插件可以完全不依赖平台独立工作，结果在插件弹窗 (Popup) 中查看

## 与平台的数据回连

当 PentaMind 平台（后端）在运行（默认 http://localhost:8080）时，插件会自动将数据回传给平台，实现大屏监控联动：

1. **心跳保活 (`/api/plugin/heartbeat`)**：插件加载后，每 30 秒自动向平台发送一次心跳，包含插件名字（`Extension`）、版本号和类型。首次心跳会自动在后台注册该插件。
2. **扫描结果上报 (`/api/plugin/report`)**：当插件在某个 Tab 页完成一次页面扫描（识别到元素和相关的 API 拦截），会自动将整理后的数据发送至平台，平台记录后展示在【仪表盘】的近期扫描任务和统计卡片中。

> **注意**：如果平台未运行或不可达，心跳和数据上报会**静默失败**，不会影响插件自身的独立工作和性能。

## 开发与安装

1. 打开 Chrome 浏览器的 **扩展程序** 页面（`chrome://extensions/`）
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择此 `extension/` 文件夹即可。
4. 如修改了 `background.js` 等后台脚本，需要在扩展页面点击刷新按钮使其生效。
